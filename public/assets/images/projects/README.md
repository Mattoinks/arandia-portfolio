# Project thumbnails

Drop live-preview screenshots here, named after each project's `slug` in
`src/lib/data.ts`:

- `ledger-core.png`
- `pulse-metrics.png`
- `atlas-auth.png`

Recommended: 1200×750 (16:10), WebP or PNG, under 300KB.

Reference from code as `/assets/images/projects/<slug>.png`. See `src/lib/data.ts`
for where to add a `thumbnail` field once these exist — the project cards don't
render one yet.
